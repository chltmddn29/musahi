## 이슈

### QA-001 설정 탭에 알림 동기화 오류 배너가 계속 표시됨
- 위치: 설정 탭 상단
- 증상: "알림 설정을 서버에 반영하지 못했습니다. 연결 후 다시 시도해주세요." 배너가 뜨고, 다시 시도를 눌러도 사라지지 않음
- 추정 원인: iOS 시뮬레이터가 APNS 토큰을 발급하지 못해 `NotificationService._waitForApnsToken()`이 10초 뒤 `TimeoutException`을 던짐 (`lib/core/notifications/notification_service.dart`). 로그로 확정하지는 못함
- 추가 확인: 알림 토글을 켜면 화면상 토글은 바뀌지만 배너는 그대로여서, 로컬 설정과 서버 토픽 구독이 어긋날 수 있음
- 심각도: 낮음 (시뮬레이터 한정 가능성). 실기기에서 재확인 필요
- 상태: 미확인

### QA-002 동 단위 재난 지역은 지도가 표시되지 않음
- 위치: 재난문자 상세 > 재난 지역 지도 (예: 서울특별시 성동구 하왕십리동 화재 문자)
- 증상: 지도 대신 "재난 지역 위치를 표시할 수 없습니다." 문구만 표시됨
- 확인한 내용: 서버 `GET /disasterAreas` 응답이 구 단위("서울특별시 성동구", "부산광역시 사하구")는 좌표를 주지만 동 단위("서울특별시 성동구 하왕십리동")는 `{"areas":[]}`를 반환함. 앱 오류가 아니라 Cloud Function 쪽 지역 매칭 문제
- 영향: 동 단위로 수신지역이 오는 문자는 재난 지역 지도와 "재난 지역 대피소"의 기준 위치를 잡지 못할 수 있음
- 심각도: 중간
- 상태: 미해결 (백엔드 확인 필요)

### QA-003 언어 설정을 바꿔도 앱 문구가 번역되지 않음
- 위치: 설정 > 언어 설정
- 증상: English/中文/日本語를 선택하면 라디오 선택과 설정 화면의 현재 언어 표시만 바뀌고, 화면 제목·버튼 등 앱 문구는 모두 한국어 그대로임
- 확인한 내용: `currentLanguage`는 `language_settings.dart`와 설정 화면(표시용)에서만 사용됨. `flutter_localizations`/l10n 설정이 없고 `MaterialApp.router`에 `locale`도 연결돼 있지 않음
- 심각도: 중간 (기능이 있는 것처럼 보이지만 동작하지 않음. 미구현이면 선택지를 숨기거나 "준비 중" 표시 필요)
- 상태: 미해결

### QA-004 안전 연락처 전화번호 검증이 느슨하고 지역번호 2자리를 허용하지 않음
- 위치: 설정 > 안전 연락처 관리 > 연락처 추가 (`lib/features/setting/presentation/setting_detail/add_contact_page.dart`)
- 증상 1: `123-0100-0000`처럼 010 등으로 시작하지 않는 번호도 추가 버튼이 활성화됨
- 증상 2 (코드 기준, 시뮬레이터에서 직접 입력해 보지는 않음): 검증 정규식이 `^\d{3}-\d{3,4}-\d{4}$`라 `02-1234-5678`처럼 앞자리가 2자리인 번호는 통과하지 못함
- 영향: 안전 상태를 공유할 연락처인데 잘못된 번호가 저장될 수 있고, 서울 지역번호 번호는 등록 불가
- 심각도: 낮음~중간
- 상태: 미해결 (의도된 정책인지 확인 필요)

### QA-005 안전 공유 완료 화면이 "전송 완료"라고 표시하지만 실제로는 전송되지 않음
- 위치: 공유 탭 > "저는 안전합니다 (공유하기)" > 완료 화면
- 증상: 초록 체크와 큰 제목 "전송 완료", "공유 대상: (이름)", 전송 시각이 표시됨. 같은 화면 하단에 작은 글씨로 "완료 화면 미리보기입니다. 실제 메시지는 전송되지 않았습니다."가 있음
- 영향: 재난 상황에서 사용자가 가족에게 안전 메시지가 갔다고 오해할 수 있음. 공유 탭에도 "현재는 미리보기이며 실제 메시지는 전송되지 않습니다"라는 문구가 있으나 작은 회색 글씨임
- 심각도: 높음 (실제 전송이 구현되기 전까지는 제목을 "미리보기 완료" 등으로 바꾸거나 경고를 눈에 띄게 해야 함)
- 상태: 해결됨 (완료 화면의 제목을 "미리보기 완료"로, 아이콘을 체크에서 안내 아이콘으로 바꾸고 "실제 메시지는 전송되지 않았습니다."를 굵게 제목 바로 아래에 배치. "공유 대상"은 "미리보기 대상"으로 변경. 공유 탭 하단의 작은 안내문은 그대로임)

### QA-006 연락처 삭제 시 확인/되돌리기가 없음
- 위치: 설정 > 안전 연락처 관리, 관심지역 관리의 X 버튼
- 증상: X를 누르면 확인창 없이 바로 삭제됨. 연락처 추가 시에는 스낵바가 뜨지만 삭제 시에는 되돌리기 안내가 없음
- 심각도: 낮음
- 상태: 미해결

### 참고 (이슈 아님)
- 시뮬레이터에 한글 키보드가 켜져 있어 영문 입력이 자모로 들어감. 앱 문제가 아니라 테스트 환경 문제
- 필터 칩 목록이 스크롤 경계에서 잘려 보이는 것은 `CategorySelector` 주석상 의도된 디자인
